## 今日のTips: Reactのmemoは新しいオブジェクト・関数をpropsに渡すと効果を失う

`memo`でラップしたコンポーネントは、propsが前回と同じ場合だけ再レンダリングをスキップする。しかし親コンポーネントがレンダリングのたびに新しいオブジェクト・配列・関数をインラインで生成してpropsに渡していると、参照が毎回変わるため`memo`の効果は失われる。公式ドキュメントも「たった1つの“常に新しい”値だけで、コンポーネント全体のメモ化を壊すのに十分」と明記している。

対処法は、対象の値を`useMemo`（オブジェクト・配列）や`useCallback`（関数）でキャッシュし、依存配列が変わらない限り同じ参照を再利用させることだ。

```tsx
function Page() {
  const [name, setName] = useState('Taylor');
  const person = useMemo(() => ({ name }), [name]);
  return <Profile person={person} />; // person の参照が安定する
}

const Profile = memo(function Profile({ person }) {
  // ...
});
```

<Tip label="▶ 補足">
関数を渡す場合は、コンポーネント外で定義して不変にするか、`useCallback`で定義をキャッシュする。それ以外の場面で`memo`を使っても大きな害はないが、効果が出るのはpropsの参照が安定している場合に限られる。
</Tip>
