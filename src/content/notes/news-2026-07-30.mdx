## 川崎重工、乗馬のように体重移動で操る四脚オフロードモビリティ「CORLEO」の実用化ロードマップを公表

## 今日のTips: Prisma 7でコネクションプールのデフォルトサイズが「CPUコア数×2+1」から固定値10に変わった

Prisma 6以前は、コネクションプールのサイズ（`connection_limit`）が明示的に指定しない限り`num_cpus::get_physical() * 2 + 1`という計算式で自動決定されていた。CPUコア数が多いマシンほどプールも大きくなる仕様だったが、Prisma 7でドライバーアダプター方式に移行したことで、プールの設定はドライバー自体が持つ値に委ねられるようになり、PostgreSQL/MySQL/SQL Serverいずれも固定値10がデフォルトになった。

```ts
// v6以前: マシンのCPUコア数に応じて自動でプールサイズが変動
// v7以降: ドライバーアダプター側のデフォルトは固定値10
const adapter = new PrismaPg({
  connectionString,
  // 明示的に指定しない限りプールサイズは10
});
```

<Tip label="▶ 補足">
コア数の多いマシンで旧来の計算式による大きめのプールを前提に運用していた場合、v7に上げると気づかないうちにプールが小さくなることがある。高並行度が必要な環境ではアダプター初期化時に明示的にプールサイズを指定した方が安全。
</Tip>
