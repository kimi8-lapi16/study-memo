## 今日のTips: Node.jsは、catchし忘れたPromiseの拒否を既定でプロセスクラッシュとして扱う

`.catch()`も`try/catch`も付けずに拒否（reject）されたPromiseを放置すると、Node.jsは既定でそれを「未処理の例外」として扱い、プロセスごと終了させる。公式ドキュメントも「`unhandledRejection`イベントが発行されても処理されなければ、未捕捉の例外として扱われる」と明記している。

```js
// これは何もログを出さないまま、プロセスをクラッシュさせる
Promise.reject(new Error('boom'));
```

対処はシンプルで、Promiseチェーンの末尾に`.catch()`を付けるか、`async`関数内なら`try/catch`で囲えばよい。

```js
Promise.reject(new Error('boom')).catch((err) => {
  console.error('拾った:', err.message); // ここでハンドリングできる
});
```

<Tip label="▶ 補足">
`process.on('unhandledRejection', ...)`でグローバルに拾うこともできるが、これはあくまでログ出力や後始末のための最終防衛線。個々のPromiseでの捕捉漏れを覆い隠す目的で使うと、本来気付くべきバグを見逃しやすくなる。
</Tip>
