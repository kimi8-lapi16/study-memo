## 今日のTips: TypeScriptの`const`型パラメータ、呼び出し時のリテラルを`as const`相当で推論

TypeScript 5.0で追加された型パラメータの`const`修飾子を使うと、呼び出し側で`as const`を書かなくても、渡した値をリテラル型のまま推論できる。

```ts
type HasNames = { names: readonly string[] };

function getNamesExactly<const T extends HasNames>(arg: T): T["names"] {
  return arg.names;
}

// 推論結果: readonly ["Alice", "Bob", "Eve"]
const names = getNamesExactly({ names: ["Alice", "Bob", "Eve"] });
```

<Note>`const`修飾子は呼び出し式の中に直接書かれたリテラルにのみ効く。事前に変数へ代入した値を渡しても効果はない。また、制約に可変の配列型(`string[]`等)を使うと`readonly`な推論結果がその制約に代入できず推論が制約側にフォールバックするため、制約自体を`readonly`配列にする必要がある。</Note>

参考: [TypeScript: Documentation - TypeScript 5.0](https://www.typescriptlang.org/docs/handbook/release-notes/typescript-5-0.html)
