## 今日のTips: Prisma ORM 8で`$transaction`が廃止、書き込み競合は自前でリトライが必要に

Prisma ORM 8では、これまでのインタラクティブトランザクション`$transaction(async (prisma) => ...)`が廃止され、`db.transaction(async (tx) => ...)`に統合された。コールバック内のクエリは`prisma`ではなく引数の`tx`経由で実行する。

<Note>
API統合に伴い`isolationLevel`・`timeout`・`maxWait`のオプションは無くなり、分離レベルはコールバック先頭で`SET TRANSACTION ISOLATION LEVEL`を自前で実行する必要がある。さらに書き込み競合(エラーコード`40001`・`40P01`)も自動リトライされなくなったため、`db.transaction`の呼び出しをリトライ処理で囲む実装が必須になる。配列形式(`$transaction([...])`)には後継APIが無く、コールバック内でクエリを順に書いて戻り値をまとめることで同じ原子性を再現する形に統一された。
</Note>

```ts
// ORM 8
const result = await db.transaction(async (tx) => {
  const user = await tx.orm.public.User.create({ email, name });
  return tx.orm.public.Post.create({ title, published: false, authorId: user.id });
});
```
