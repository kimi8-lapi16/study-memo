## 日本サッカー協会「JFA Passport」に不正アクセス、ログアウト・再ログイン控えるよう呼びかけ

マイクロソフトは10月19日、.NETのSDK・ランタイム・コンパイラなどを一括導入・バージョン管理できるツールチェーンマネージャ「dotnetup」のパブリックプレビューを公開した。

## 今日のTips: TypeScriptのMapped Typesの`as`句、キー名を変換しながら新しい型を作れる

TypeScript 4.1で、Mapped Types(マップ型)にキーを再マッピングする`as`句が追加された。それまでのマップ型は入力型のキーをそのまま使うしかなかったが、`as`句にテンプレートリテラル型を渡せば元のキー名から新しいプロパティ名を生成でき、`never`を返すキーは結果の型から除外されるため`Omit`相当の絞り込みにも使える。

```ts
type Getters<T> = {
  [K in keyof T as `get${Capitalize<string & K>}`]: () => T[K];
};

interface Person {
  name: string;
  age: number;
}
type LazyPerson = Getters<Person>;
// => { getName: () => string; getAge: () => number }

type RemoveKind<T> = {
  [K in keyof T as Exclude<K, 'kind'>]: T[K];
};
```

<Note>
`as`句に書けるのは型(文字列・数値・シンボルのユニオン)で、変換自体はテンプレートリテラル型や`Exclude`など既存の型演算と組み合わせて行う。`never`を返したキーは単純に結果の型から取り除かれる。
</Note>

参考: [TypeScript Release Notes — Key Remapping in Mapped Types](https://www.typescriptlang.org/docs/handbook/release-notes/typescript-4-1.html)
