## 今日のTips: TypeScriptの`NoInfer<T>`、意図しない型引数の推論を防ぐ

TypeScript 5.4で追加された`NoInfer<T>`は、ジェネリック関数の引数の型を型推論の候補から外すためのユーティリティ型だ。

```typescript
function createStreetLight<C extends string>(
  colors: C[],
  defaultColor?: NoInfer<C>,
) {}

createStreetLight(['red', 'yellow', 'green'], 'blue');
// Error: Argument of type '"blue"' is not assignable
// to parameter of type '"red" | "yellow" | "green"'.
```

`defaultColor`を単なる`C`のままにすると、渡した`"blue"`も型引数`C`の推論候補に含まれてしまい、配列にない色でも型チェックを通ってしまう。`NoInfer<C>`で囲むと`colors`だけが推論の唯一の根拠になり、`defaultColor`側の値は推論に影響しないため、配列外の値を渡した時点でエラーにできる。従来は使われない型パラメータ`D extends C`を追加してごまかす回避策もあったが、`NoInfer`の方が意図を素直に表現できる。

<Tip>
`NoInfer<T>`自体は型を変えず「推論候補から外す」目印にすぎないため、型チェックを厳しくする効果は推論結果の変化を通じた副次的なものである点に注意。
</Tip>
