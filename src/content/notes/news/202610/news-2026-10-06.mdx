## 今日のTips: Node.jsのグローバル`structuredClone`、関数やSymbolを渡すとDOMExceptionで落ちる

Node.js 17以降はWHATWGの構造化クローンアルゴリズムを実装した`structuredClone`がグローバルに使え、importなしで深いコピーが作れる。ただしMapやSet、Dateなどはコピーできる一方、関数やSymbolは複製できずDOMExceptionを投げて落ちる。

```js
const config = { retry: 3, onError: () => {} };
structuredClone(config);
// DOMException [DataCloneError]: () => {} could not be cloned.
```

<Tip>
型チェックでは拾えない落とし穴。コールバックを含むオブジェクトや、クラスインスタンス・DOM風のハンドルなどをうっかり`structuredClone`に渡すと実行時に初めて例外で気づくことになる。状態を複製したいだけなら対象をプレーンなデータ(値・配列・プレーンオブジェクト)に絞り、関数や振る舞いを含むものは別経路で渡す。
</Tip>

参考: [Global objects: structuredClone() – Node.js Docs](https://nodejs.org/api/globals.html#structuredclonevalue-options)
