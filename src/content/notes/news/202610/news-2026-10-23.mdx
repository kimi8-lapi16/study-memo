## 今日のTips: React 19で`<Context>`をプロバイダーとして直接使えるように(`Context.Provider`はレガシー扱い)

React 19以降、Contextオブジェクトそのものを`<Context value={...}>`のようにプロバイダーとしてレンダリングできるようになった。従来のように`<Context.Provider value={...}>`と書く必要がなくなる。

```jsx
// React 19以降
<ThemeContext value={theme}>
  <Page />
</ThemeContext>

// 従来の書き方（引き続き動作する）
<ThemeContext.Provider value={theme}>
  <Page />
</ThemeContext.Provider>
```

<Note>
公式ドキュメントは`Context.Provider`を「React 19以前の、値を提供するためのレガシーな方法」と位置付けている。正式な非推奨(deprecated)の告知や削除予定の言及はまだないが、新規コードでは`<Context.Provider>`より`<Context>`を直接使う書き方に揃えておくと、将来的な移行コストを抑えられる。
</Note>
