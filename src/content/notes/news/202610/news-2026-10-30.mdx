## 今日のTips: Node.jsの`require()`、ES Modulesを同期的に読み込めるように

Node.jsの`require()`は、一定の条件を満たすES Module(ESM)を同期的に読み込める。v22.0.0・v20.17.0で追加され、v23.0.0/v22.12.0で`--experimental-require-module`フラグが不要になり、v25.4.0で実験的機能の扱いが外れた。

```js
// distance.mjs
export function distance(a, b) {
  return Math.sqrt((b.x - a.x) ** 2 + (b.y - a.y) ** 2);
}
```

```js
const { distance } = require('./distance.mjs');
```

読み込めるのは、モジュール自体とそのインポートグラフ全体にトップレベル`await`が含まれない場合のみ。含まれていると`ERR_REQUIRE_ASYNC_MODULE`が投げられ、代わりに`import()`を使う必要がある。対象となるのは`.mjs`拡張子、または`package.json`に`"type": "module"`指定がある`.js`、もしくはCommonJS指定が無くESM構文を含む`.js`。

<Note>`default`エクスポートがある場合、CommonJS側の互換のため`__esModule: true`が自動付与される。この値は実験的で変更される可能性があるため、自前のコードから依存しないこと。</Note>

参考: [Node.js Docs: Loading ECMAScript modules using require()](https://nodejs.org/api/modules.html#loading-ecmascript-modules-using-require)
