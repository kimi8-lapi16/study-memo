## 今日のTips: TypeScriptの条件型、ユニオンを渡すと勝手に「分配」されることがある

TypeScriptの条件型(`T extends U ? X : Y`)は、`T`がジェネリックな型パラメータでユニオン型を渡されると「分配法則的(distributive)」に振る舞う。ユニオンの各メンバーに対して個別に条件型が適用され、結果も新たなユニオンになる。

```ts
type ToArray<T> = T extends any ? T[] : never;

// string[] | number[] になる(分配される)
type A = ToArray<string | number>;

// (string | number)[] になる(分配を抑制)
type ToArrayNonDist<T> = [T] extends [any] ? T[] : never;
type B = ToArrayNonDist<string | number>;
```

<Tip>
分配は通常は望ましい挙動だが、ユニオン型全体を1つの型として扱いたい場合は`extends`の両辺を`[T] extends [U]`のように角括弧で囲むと抑制できる。
</Tip>

参考: [Conditional Types - TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/2/conditional-types.html)
