## Meta、AIエージェント「Muse」とつながる自作ガジェット向けSDKをオープンソースで公開

Metaは10月2日(現地時間)、AIエージェント「Muse」と接続するカスタムデバイスを誰でも自作できる「Muse Gadgets」プロジェクトを発表した。

AI・LLM動向案件。ESP32向けファームウェアとLinux向けSDKをApache License 2.0でGitHub上に公開し、市販のESP32ボードやRaspberry Piにディスプレイ・ボタン・センサーなどを組み合わせてMuse対応デバイスを作れるようにした。米国のMuseサブスク契約者向けには完成品デバイス「Muse Home Link」も10月から先着順で無料提供する。開発者向けのDiscordコミュニティも用意し、自己責任での利用を前提に作例の共有を促している。

## Apple、macOSの「フルディスクアクセス」に追加の制御を導入へ 「AIエージェントの進化でリスクが大幅に増大」

Appleは10月2日(現地時間)、macOSの強力な権限「フルディスクアクセス」について、付与時の制御を強化する方針を発表した。

新技術紹介案件。フルディスクアクセスは本来バックアップアプリ等が正常動作するための権限だが、一部の開発者がファイル・メール・メッセージ・閲覧履歴まで露出しかねない形で利用しているとし、今後は「非常に明示的なユーザー操作」を経た場合のみ付与できるよう制御を追加する。背景にはMetaのAIエージェント「Muse」のメッセージデータ取り扱いが議論を呼んだ経緯があり、AIエージェントの能力・自律性が高まるほどこの権限に伴うリスクは大きくなるとAppleは指摘している。実装時期や対象のmacOSバージョンは未発表。

<Note>
常時稼働型のAIエージェントがローカルファイルへ広範にアクセスする構成が増えるほど、OS側の権限設計も見直しを迫られる好例。
</Note>

## 今日のTips: Prisma ORM 7のRust-free化、ドライバアダプタを自分で入れないとクライアントが動かない

Prisma ORM 7.0.0(2025年11月19日リリース)で、Rustエンジンを使わない「Rust-free Prisma Client」がデフォルトになった。バンドルサイズが約90%縮小し最大3倍速くなるなどの利点がある一方、これまでRustエンジンに同梱されていたデータベースドライバが同梱されなくなり、必要なドライバアダプタを自分で明示的にインストールしないとクライアントが動作しない。

```prisma
// schema.prisma: generatorの指定を変更
- provider = "prisma-client-js"
+ provider = "prisma-client"
// output パスの指定も必須になった
+ output   = "../src/generated/prisma"
```

<Tip>
v6.16.0からオプトインで導入されていたRust-free Clientが7.0.0でデフォルト化された変更。v6以前からのアップグレードでは、generatorプロバイダの変更と出力パス指定に加えて、使用するDB用のドライバアダプタ(`@prisma/adapter-pg`など)の追加インストールが必要になる点を忘れると、ビルドは通ってもクライアント初期化時に失敗する。
</Tip>

参考: [Prisma ORM v7.0.0: Rust-free Prisma Client becomes the default](https://www.prisma.io/changelog/2025-11-19)
