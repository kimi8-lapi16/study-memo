## 今日のTips: Reactの`use()`、条件分岐やループの中で呼べる唯一の「Hookではない」関数

Reactの`use()`は、公式ドキュメントで明確に「Hookではない」と位置付けられている特殊な関数。`useState`などのHookは呼び出し場所がコンポーネント・カスタムHookのトップレベルに限られるが、`use()`は`if`文やループの中でも呼べる。

```tsx
function HorizontalRule({ show }: { show: boolean }) {
  if (show) {
    const theme = use(ThemeContext);
    return <hr className={theme} />;
  }
  return false;
}
```

Promiseを渡した場合は解決値を返し、保留中は呼び出し元を`<Suspense>`の範囲でサスペンドさせる。ただしレンダー中に新しいPromiseを作ると毎回サスペンドし続けるため、Promiseはレンダーをまたいで同じインスタンスが再利用されるようキャッシュしておく必要がある。Suspense連携のため内部でthrowする仕組みなので、try-catchで囲むこともできない(エラー処理はError Boundaryに任せる)。

<Note>`use()`はコンポーネントまたは別のHookの中からのみ呼び出せる。通常の関数の中からは呼べない。</Note>
