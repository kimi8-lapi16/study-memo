## 今日のTips: TypeScriptの`NoInfer<T>`で、意図しない型引数の推論を防ぐ

ジェネリック関数では、オプション引数の値も型推論の候補に使われてしまうことがある。`NoInfer<T>`（TypeScript 5.4〜）で対象の型を囲むと、その位置を推論候補から除外できる。

```ts
function createStreetLight<C extends string>(
  colors: C[],
  defaultColor?: NoInfer<C>,
) {}

createStreetLight(["red", "yellow", "green"], "blue");
// error: Argument of type '"blue"' is not assignable to
// parameter of type '"red" | "yellow" | "green" | undefined'.
```

`NoInfer`が無い場合、`defaultColor`に渡した`"blue"`も候補に加わり`C`が`"red" | "yellow" | "green" | "blue"`と推論されてしまうため、`colors`に存在しない値でもエラーにならない。`NoInfer`で`defaultColor`側を推論対象から外すことで、`C`は`colors`の要素のみから推論され、想定外の値渡しをコンパイル時に検出できる。

<Tip label="▶ 補足">
上記のコード例は`npx tsc --noEmit --strict`で実際にエラーが発生することを確認済み。
</Tip>
