## 今日のTips: Node.jsのTypeScript型ストリッピング、`enum`や値を持つ`namespace`には対応していない

Node.jsはv22.18.0/v23.6.0以降、`.ts`ファイルを`node file.ts`でそのまま実行できる「型ストリッピング」機能をデフォルトで有効にしている。型注釈をJavaScriptへ変換するのではなく単純に取り除くだけの軽量な実装のため、`tsconfig.json`は読み込まれずDecoratorも非対応。特に注意が必要なのは、型注釈の削除だけでは表現できない「値を生成する構文」で、`enum`宣言や値を持つ`namespace`を書くと実行時に`ERR_UNSUPPORTED_TYPESCRIPT_SYNTAX`エラーになる。

```ts
// エラーになる: 値を生成する構文
enum Color {
  Red,
  Green,
}

// 動作する: 型だけのnamespace
namespace TypeOnly {
  export type A = string;
}
```

<Tip>
こうした構文を変換して動かす`--experimental-transform-types`フラグは、型ストリッピングの安定化に伴いv26.0.0で削除された。Node単体の実行では`enum`等は諦めて型注釈の除去にとどめ、必要なら事前ビルドや`tsx`などのサードパーティツールを使う設計にするのが安全。
</Tip>
