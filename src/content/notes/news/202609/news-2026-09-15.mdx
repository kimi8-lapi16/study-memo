## ヤマハ、音源から3分でピアノ譜を自動生成する「Piano Sheet Converter」β版を無料公開

ヤマハは9月11日、音源ファイルを読み込むだけでピアノ譜を自動生成するアプリ「Piano Sheet Converter」のβ版をWindows/macOS向けに無料公開した。

新技術紹介案件。いわゆる「自動耳コピ」機能を搭載し、標準的な楽曲であれば読み込みから約3分でピアノ譜を作成できる。譜面は入門・初級・中級・上級の4段階で作り分けられ、アプリ内での編集や再生も可能。完成した楽譜はPDF・MIDI・MusicXML形式で書き出せる。10月末までのβ期間中は有料機能も無料で使えるが、商用利用は不可で私的利用のみが対象、GDPR適用地域（欧州経済領域など）では利用できない。正式版はWindows/macOS向けが2026年秋、iOS/Android向けが2027年春ごろを予定している。

## 今日のTips: NestJSのREQUESTスコープProvider、それに依存するControllerまでスコープが伝播する

NestJSでプロバイダーを`Scope.REQUEST`にすると、リクエストごとに新しいインスタンスが生成されるようになるが、公式ドキュメントは「A controller that depends on a request-scoped provider will, itself, be request-scoped.」と明記している。スコープの影響はそのプロバイダー単体にとどまらず、それに依存するコンポーネントへ連鎖的に伝播する。

```ts
@Injectable({ scope: Scope.REQUEST })
export class CatsService {}

@Controller('cats')
export class CatsController {
  // CatsServiceに依存しているため、CatsController自体もREQUESTスコープになる
  constructor(private catsService: CatsService) {}
}
```

<Note>
公式ドキュメントはパフォーマンスへの影響にも言及しており、「適切に設計されたアプリケーションであれば、REQUESTスコープのプロバイダーを使ってもレイテンシへの影響はおよそ5%程度に収まるはず」としつつ、リクエストのたびにインスタンス生成が発生し平均応答時間が遅くなる点も明確に警告している。テナントIDなど本当にリクエスト単位の状態が必要な箇所だけに絞って使うのが安全。
</Note>
