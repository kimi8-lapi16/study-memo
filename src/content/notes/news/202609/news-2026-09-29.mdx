## 今日のTips: React 19、ref callbackはcleanup関数を返せるようになった

React 19以降、DOM要素やコンポーネントインスタンスに渡す`ref`のコールバック関数は、`useEffect`と同じように「クリーンアップ関数」を返せるようになった。返した関数はrefがデタッチされるとき(別のref callbackに差し替えられたときや、コンポーネントがアンマウントされたとき)に呼ばれる。

```tsx
<div
  ref={(node) => {
    if (!node) return;
    const observer = new ResizeObserver(() => {/* ... */});
    observer.observe(node);
    // クリーンアップ関数を返す
    return () => observer.disconnect();
  }}
/>
```

公式ドキュメントには、クリーンアップ関数を返さない場合は従来どおりデタッチ時に`node`へ`null`が渡される互換動作になるが、「この動作は将来のバージョンで削除される」と明記されている。既存コードをReact 19に上げただけでは動くが、いずれ`null`引数での呼び出しに頼ったコードは書き換えが必要になる。

<Tip>
開発時のStrict Modeでは、本来のマウントの前に余分なsetup→cleanupサイクルが1回追加実行される。クリーンアップ関数を書かずに副作用だけ仕込んでいるref callbackは、このストレステストで不整合が顕在化しやすい。
</Tip>
