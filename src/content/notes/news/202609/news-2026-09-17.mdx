## 今日のTips: `useDeferredValue`は受け取り側を`memo`でラップしないと効果が出ない

Reactの`useDeferredValue`は値の更新を遅延させ、重い再レンダリングを裏側で処理するためのフックだが、それを使うコンポーネント自体を`memo`でラップしていないと効果が出ない落とし穴がある。遅延値はそのコンポーネントの外側で作られる新しいpropsの一部にすぎず、`memo`が無ければ親の再レンダリングのたびに「遅延済みの値」を受け取った子も含めて丸ごと再レンダリングされてしまうため、遅延の恩恵(古い結果を表示しつつ裏で低優先度の再計算を行う)が得られない。

```jsx
function App() {
  const [text, setText] = useState('');
  const deferredText = useDeferredValue(text);
  // SlowListはmemoでラップされていて初めて
  // 「deferredTextが変わった時だけ」低優先度で再レンダリングされる
  return <SlowList text={deferredText} />;
}
```

<Note>
公式ドキュメントも実装例で「SlowListはmemoでラップされている必要がある」と明記している。`useDeferredValue`自身は値をメモ化する仕組みではなく、あくまで「更新の優先度を下げる」だけの機能である点に注意。
</Note>
