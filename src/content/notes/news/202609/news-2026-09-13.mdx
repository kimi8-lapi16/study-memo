## 今日のTips: TypeScriptの`using`宣言、複数リソースは後入れ先出し（LIFO）で破棄される

TypeScript 5.2で追加された`using`宣言は、スコープを抜けるタイミングで自動的に`Symbol.dispose`を呼び出し、ファイルハンドルやDB接続などのリソースを解放できる機能。正常終了・`return`による早期終了・例外送出のいずれでも確実に呼ばれ、`try/finally`を書かずに済む。

同じスコープに複数の`using`変数がある場合、破棄は**宣言と逆順（後入れ先出し）**で行われる点に注意。

```ts
function loggy(id: string) {
  return { [Symbol.dispose]() { console.log(`dispose ${id}`); } };
}

function run() {
  using a = loggy('a');
  using b = loggy('b');
}
run();
// dispose b
// dispose a
```

<Note>
非同期な後始末が必要な場合は`await using`を使うと`Symbol.asyncDispose`がawaitされる。また破棄処理自体が例外を投げた場合は、元の例外を`suppressed`プロパティに保持した`SuppressedError`としてまとめて報告される。
</Note>

参考: [TypeScript 5.2 Release Notes](https://www.typescriptlang.org/docs/handbook/release-notes/typescript-5-2.html)
