## 今日のTips: React 19、関数コンポーネントがrefをpropとして直接受け取れる(forwardRef不要に)

React 19以降、関数コンポーネントは`ref`を通常のpropとして直接受け取れるようになり、`forwardRef`でのラップが不要になった。

```tsx
// React 19
function MyInput({ placeholder, ref }: Props) {
  return <input placeholder={placeholder} ref={ref} />;
}

<MyInput ref={inputRef} />;
```

<Tip>
`forwardRef`自体はReact 19でも動作するが、Reactチームは将来的に非推奨化・削除する方針を明言しており、移行用のcodemodも提供予定としている。新規コンポーネントはpropとして`ref`を受け取る書き方に揃えておくとよい。なお、この変更はクラスコンポーネントには適用されない。
</Tip>
