## GitLabの最大深刻度パストラバーサル脆弱性、公開翌日から実悪用偵察が発生

GitLabは9月10日、リポジトリのコミットAPIにおける最大深刻度（CVSS 10.0）のパストラバーサル脆弱性CVE-2026-85706を修正した。公開から1日で未パッチサーバーへの偵察活動が観測されている。

セキュリティインシデント案件。パス制限の不備と認証の欠落により、未認証の攻撃者がコミットAPIへのリクエストだけで設定ファイルや認証情報など本来公開されないサーバー内のファイルを読み取れる状態だった。セキュリティ研究者「s3ntago」がHackerOne経由で報告し、影響を受けるのはGitLab CE/EEの18.7以降19.1.8未満・19.2系19.2.6未満・19.3系19.3.2未満で、修正版は19.1.8・19.2.6・19.3.2。watchTowrのハニーポットでは9月11日6時（UTC）時点で未パッチサーバーへの探索的アクセスを検知しており、セルフホストGitLabの利用者は早急なアップデートが必要。

出典: [BleepingComputer](https://www.bleepingcomputer.com/news/security/gitlab-urges-users-to-patch-max-severity-path-traversal-flaw/)

## パスキー詐称のソーシャルエンジニアリングでMicrosoft 365侵害が拡大

## 今日のTips: `Object.groupBy()`が返すのはプロトタイプなしのオブジェクト、`hasOwnProperty()`は使えない

ES2024で追加された`Object.groupBy()`は配列を条件でグルーピングして返す便利な関数だが、返り値は通常の`Object`インスタンスではなく**プロトタイプを持たない（`null`-prototype）オブジェクト**である。そのため`Object.prototype`由来のメソッドを直接呼び出すとエラーになる。

```js
const items = [
  { name: 'asparagus', type: 'vegetables' },
  { name: 'banana', type: 'fruit' },
];

const grouped = Object.groupBy(items, ({ type }) => type);

grouped.hasOwnProperty('fruit');
// TypeError: grouped.hasOwnProperty is not a function

Object.prototype.hasOwnProperty.call(grouped, 'fruit'); // true
```

<Note>
`Object.keys()` / `Object.values()` / `Object.entries()` や `for...in` はプロトタイプチェーンに依存しないため問題なく使える。詰まりやすいのは`hasOwnProperty()`や`toString()`など`Object.prototype`のメソッドを直接呼んだ場合で、必要なら`Object.prototype.xxx.call(grouped, ...)`の形で呼び出す。
</Note>
