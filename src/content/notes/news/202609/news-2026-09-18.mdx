## 今日のTips: `structuredClone()`は関数やDOMノードを渡すと例外を投げる

`structuredClone()`はDate・Map・Set・RegExp・TypedArrayなど幅広い型をディープコピーできる便利な標準関数だが、万能ではない。オブジェクトのプロパティに関数(メソッド)やDOMノードが含まれていると、複製不可能な値として`DataCloneError`例外を投げて失敗する。また複製できた場合でも、getter/setterやプロトタイプチェーン、クラスのプライベートフィールドは失われ、`RegExp`の`lastIndex`も保持されないといった制限がある。

```js
const state = {
  count: 1,
  // メソッドを持つオブジェクトはstructuredCloneできない
  increment() {
    this.count++;
  },
};

structuredClone(state);
// => DataCloneError: increment() {...} could not be cloned.
```

<Note>
Node.jsでは`structuredClone`はグローバル関数としてv17.0.0から利用可能(WHATWGのstructured cloneアルゴリズムに準拠)。JSONに変換できない値も多く複製できる一方、「メソッド付きのクラスインスタンス」のようなオブジェクトを丸ごとコピーしたい場合は素直に使えない点に注意。
</Note>
