## Google、Android+ChromeOSの新カテゴリPC「Googlebook」発表 899ドルから

Googleは9月22日、AndroidとChromeOSを組み合わせた新カテゴリのノートPC「Googlebook」の予約受付を開始した。価格は899ドル(約14万円)からで、米国では10月4日、その他地域では10月5日に発売する。

新技術紹介案件。AI機能群「Gemini Intelligence」向けに設計したプレミアムフラグシップ機で、45TOPS以上のNPUとセキュリティチップ「Titan C」を搭載する。スマートフォンでの作業をそのまま引き継げる「Continue On」機能や、Google Playストアからのアプリ直接インストールにも対応する。Googlebook自体はGoogleの自社製ではなく、Acer・ASUS・Dell・HP・Lenovoの5社が5モデルを展開する形で、OSアップデートは最長10年間提供される。日本は発売対象に含まれていない。

## Google、位置情報データの取り扱いでアイルランドDPCからGDPR制裁金403百万ユーロ

アイルランドのデータ保護委員会(DPC)は9月21日、Googleの位置情報データ処理に関するGDPR違反について403百万ユーロ(約645億円)の制裁金を科したと発表した。

法改正・規制動向案件(EU・GDPR執行)。対象は「ウェブとアプリの活動」「位置情報履歴」「位置情報の精度」の3機能で、DPCはGoogleが透明性の要件を満たさず、必要以上に長く位置情報を保持していたと指摘した。調査は消費者団体からの申し立てを受けて2020年2月に開始され、GDPR施行の2018年5月から2020年2月までの処理が対象となった。GoogleはDPCの指摘について「既に見直した過去の方針」とコメントしており、6カ月以内に処理方法をコンプライアンス対応させるよう命じられている。

## 今日のTips: Prisma Clientの`omit`、機密フィールドをクライアント全体で隠せる

Prisma Clientの`omit`オプションを使うと、`password`のような機密フィールドを個別クエリだけでなくクライアント全体でデフォルト除外できる。

```typescript
const prisma = new PrismaClient({
  omit: {
    user: {
      password: true,
    },
  },
});

const user = await prisma.user.findUnique({ where: { id: 1 } });
// user.password は存在しない（型上も除外される）
```

<Tip>
`select`で必要なフィールドをその都度指定する方式は、スキーマに新しい機密カラムを追加した際にそれを見落として返してしまう事故が起きやすい。`omit`は逆に「基本はそのまま返し、機密フィールドだけ隠す」方式なので、カラムを増やしてもデフォルトで安全側に倒せる。個別クエリ側で`omit: { password: false }`と指定すれば、その場だけ除外を解除することも可能。
</Tip>

参考: [Prisma: Excluding fields](https://www.prisma.io/docs/orm/prisma-client/queries/excluding-fields)
