## 今日のTips: Prismaのカーソルページネーション、非ユニークな並び順だけでは行の重複・欠落が起こる

Prisma Clientのカーソルベースページネーションは、`cursor`にユニークなフィールド（`id`など）を指定するだけでは不十分で、`orderBy`側にも同じフィールドをタイブレーカーとして含める必要がある。公式ドキュメントは「`createdAt`はユニークではない」と明記しており、`createdAt`のみで並び替えると、同一タイムスタンプの行を挟むページ境界で重複や欠落が発生し得る。

```ts
// 注意: cursorはidだが、並び順はcreatedAtのみ
await prisma.post.findMany({
  take: 10,
  skip: 1,
  cursor: { id: lastId },
  orderBy: { createdAt: 'desc' },
});

// 対策: idをタイブレーカーとしてorderByに追加する
await prisma.post.findMany({
  take: 10,
  skip: 1,
  cursor: { id: lastId },
  orderBy: [{ createdAt: 'desc' }, { id: 'desc' }],
});
```

<Note>
一括インポートなど同一ミリ秒に複数行が作成されるケースほど発生しやすい。件数が少ないテスト環境では再現しにくく、本番の大量データで初めて重複表示に気づくことが多い。
</Note>
