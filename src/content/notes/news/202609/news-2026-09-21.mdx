## 今日のTips: NestJSのInterceptor、`next.handle()`を呼ばないとルートハンドラー自体が実行されない

NestJSのInterceptorは`intercept(context, next)`の中で`next.handle()`を呼び出し、それが返すRxJSの`Observable`をそのまま（または`pipe()`で加工して）返す必要がある。これを呼ばずに独自の値を返すと、後続のルートハンドラーメソッド自体が一切実行されなくなる。

```typescript
@Injectable()
export class LoggingInterceptor implements NestInterceptor {
  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    const now = Date.now();
    return next.handle().pipe(
      tap(() => console.log(`After... ${Date.now() - now}ms`)),
    );
  }
}
```

公式ドキュメントは「`intercept()`メソッドの実装内で`handle()`を呼び出さなければ、ルートハンドラーメソッドは全く実行されない」と明記している。これはキャッシュ実装などハンドラーの実行そのものを意図的にスキップしたい場合には有用だが、うっかり`handle()`の呼び出しを忘れると、リクエストがハンドラーに到達せずレスポンスが返らないバグになる。

参考: [NestJS: Interceptors](https://docs.nestjs.com/interceptors)
