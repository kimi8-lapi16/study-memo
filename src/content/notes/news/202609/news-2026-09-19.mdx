## 今日のTips: TypeScriptの`satisfies`演算子、型チェックしつつ推論結果を狭めない

オブジェクトや配列の値がある型に合致することを確認したいとき、`: Type`という通常の型注釈を使うと、変数全体の型がその注釈の型に固定されてしまい、個々のプロパティが本来持っていたより詳細な型情報が失われることがある。

```ts
type Colors = "red" | "green" | "blue";
type RGB = [number, number, number];

// 通常の型注釈: palette.green は string | RGB 型になり、
// string 用のメソッドがそのままでは呼べない
const palette: Record<Colors, string | RGB> = {
  red: [255, 0, 0],
  green: "#00ff00",
  blue: [0, 0, 255],
};

// satisfies: 型チェックは行われつつ、green は string のまま推論される
const palette2 = {
  red: [255, 0, 0],
  green: "#00ff00",
  blue: [0, 0, 255],
} satisfies Record<Colors, string | RGB>;

palette2.green.toUpperCase(); // OK
```

TypeScript 4.9で追加された`satisfies`演算子は、式が指定した型に適合するかをチェックする一方、変数自体の型はその式から推論された最も詳細な型のまま保つ。「型チェックはしたいが、型注釈で推論結果を上書きしたくない」という場面、たとえば設定オブジェクトのキー漏れをチェックしつつ各値の詳細な型は保持したい、といったケースに向く。

参考: [TypeScript 4.9 Release Notes: The `satisfies` Operator](https://www.typescriptlang.org/docs/handbook/release-notes/typescript-4-9.html)
