## 今日のTips: `Map.groupBy()`はオブジェクトをキーにできるが、同じ参照でないと引けない

`Object.groupBy()`はキーが文字列（Symbolも可）に限られるが、`Map.groupBy()`はオブジェクトそのものをキーにできる。ただし取り出す際は、グループ化時に使ったのと**同じ参照**のオブジェクトでなければならない。

```js
const restock = { restock: true };
const sufficient = { restock: false };

const result = Map.groupBy(inventory, ({ quantity }) =>
  quantity < 6 ? restock : sufficient,
);

result.get(restock); // OK: 同じ参照
result.get({ restock: true }); // undefined: 中身が同じでも別オブジェクト
```

<Tip>
`restock`のプロパティを後から書き換えても`result.get(restock)`は引き続き取得できる。参照さえ保てば、値を可変な状態管理のキーとして使える点が`Object.groupBy()`との実用上の違いになる。
</Tip>
