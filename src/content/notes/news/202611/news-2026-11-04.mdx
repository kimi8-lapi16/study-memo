## 今日のTips: Reactの`flushSync`、Effect内で呼ぶとno-opになり警告が出る

`flushSync`はコールバック内のstate更新を同期的に反映させ、関数が返った時点でDOMの更新を保証するreact-domのAPI。通常Reactはstate更新をバッチ処理して非同期に描画するため、`onbeforeprint`のようにコールバック終了時点でDOMが最新であることを要求するブラウザAPIと連携する場合などに使う「最後の手段」とされる。

```ts
function handleClick() {
  // OK: イベントハンドラ内では安全に使える
  flushSync(() => setCount(c => c + 1));
}

useEffect(() => {
  // NG: レンダリング中・Effect内・クラスのライフサイクルメソッド内では no-op になり警告が出る
  flushSync(() => setCount(c => c + 1));
}, []);
```

<Note>頻繁に呼ぶとバッチ処理や並行レンダリングが効かなくなりパフォーマンスが低下し、保留中のSuspense境界を意図せずfallback表示させることもある。Effect内でどうしても必要な場合は`queueMicrotask`で遅延させる手もあるが、公式ドキュメントはこれを「特にパフォーマンスが悪い」回避策としている。</Note>
