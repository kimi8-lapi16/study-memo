## 今日のTips: StrictModeの開発時、useEffectは`setup→cleanup→setup`の順で1回多く実行される

Reactの`<StrictMode>`を使っていると、開発時のみすべての`useEffect`に対して「セットアップ→クリーンアップ→セットアップ」という追加の1サイクルが実行される。コンポーネント自体がアンマウント・再マウントされるわけではなく、Effectのセットアップとクリーンアップが余分に1回ずつ呼ばれる点がポイントだ。

```ts
useEffect(() => {
  const connection = createConnection(serverUrl, roomId);
  connection.connect();
  return () => connection.disconnect();
}, [roomId]);
```

<Tip>クリーンアップ関数が無いと、StrictMode下では接続が2回作られて1回も破棄されずコンソールの接続数が増え続ける。この挙動は実装の不備(クリーンアップ漏れ)を開発時に気づかせるための仕組みで、本番ビルドには影響しない。</Tip>

参考: [`<StrictMode>` – React Docs](https://react.dev/reference/react/StrictMode)
