## 今日のTips: Node.jsの`--env-file`、dotenvパッケージ不要で`.env`を直接読み込める

Node.js v20.6で追加された`--env-file`フラグを使うと、外部パッケージなしに`.env`ファイルを`process.env`へ読み込める。v24.10/v22.21で実験的機能ではなくなり安定版の機能になった。

```bash
node --env-file=.env index.js
# 複数指定も可能。後から指定したファイルが前のファイルの値を上書きする
node --env-file=.env --env-file=.env.local index.js
```

<Note>同名の変数がOS側の環境変数とファイルの両方にある場合は、OS側の環境変数の値が優先される。ファイルが存在しないとエラーになるため、存在しなくてもエラーにしたくない場合はv22.9で追加された`--env-file-if-exists`を使う。</Note>

参考: [Command-line API | Node.js v24.x Documentation - `--env-file`](https://nodejs.org/api/cli.html#--env-fileconfig)
