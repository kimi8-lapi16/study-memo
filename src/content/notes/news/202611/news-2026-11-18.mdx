## CNCF、軽量マイクロVMでLinuxアプリをネイティブ並みに高速起動する「Hyperlight-Unikraft」公開

CNCF(Cloud Native Computing Foundation)は、Linuxアプリケーションを軽量なマイクロVMで隔離実行する「Hyperlight-Unikraft」を発表した。

新技術紹介案件。仮想マシン管理ライブラリ「Hyperlight」と、必要最小限のOS機能のみを持つUnikernel構築ツールキット「Unikraft」を組み合わせたもので、アプリや実行系を再コンパイル・再ビルドせずそのままマイクロVM内で動かせる。ウォームアップ後の状態をスナップショットとして保存し、そこから起動することで高速化を実現しており、通常199ミリ秒かかるPythonスクリプトの起動が8.9ミリ秒に短縮、1000個のPythonスクリプトを3GB以内のメモリで動かせる高密度も実現したという。Python・Node.js・.NET・Java・PHP・Go・Rust・Cなど主要な実行系に対応し、LinuxのKVM/MSHV、WindowsのHypervisor Platform、Apple siliconのmacOSで動作する。仮想マシンによる強い隔離を保ちながら、ネイティブ起動に迫る速度を両立する狙いがある。

## 今日のTips: TypeScriptのassertion関数、呼び出し直後から型を絞り込める

TypeScript 3.7で追加された`asserts`構文を使うと、戻り値ではなく「呼び出したこと自体」で型を絞り込める関数を書ける。通常の型ガード(`val is T`)は`if`文の条件として使ったときしか絞り込みが効かないが、`asserts val is T`はチェックを通過して関数が正常に返った時点で、以降のスコープ全体に絞り込みが継続する。

```ts
function assertIsString(val: unknown): asserts val is string {
  if (typeof val !== "string") throw new Error("not a string");
}

function example(input: unknown) {
  assertIsString(input);
  input.toUpperCase(); // ここでは string に絞り込まれている
}
```

対して通常の型ガード関数は、戻り値を`if`で受けずに単体で呼ぶだけでは絞り込みが働かない(`input`は`unknown`のまま)。バリデーション用のユーティリティ関数を素通りさせるだけで以降のコードを型安全にできるため、「ここで検証を通れば以降は安全」という前提を書きたい場面に向いている。

<Tip>`asserts`は戻り値の型を書けないため、値を返しつつ絞り込みたい場合は`val is T`の型ガードと使い分ける必要がある。</Tip>

参考: [TypeScript Handbook — TypeScript 3.7: Assertion Functions](https://www.typescriptlang.org/docs/handbook/release-notes/typescript-3-7.html#assertion-functions)
