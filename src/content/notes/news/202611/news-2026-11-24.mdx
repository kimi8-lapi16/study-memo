## Anthropic、PRのレビューから承認までをAIで支援する「Claude Ship」をβ公開

Anthropicは2026年11月23日(現地時間)、プルリクエスト(PR)のレビュー・修正対応から承認判断までをAIエージェントが担う「Claude Ship」を公開した。

AI・LLM動向案件。Claude Shipは3つの機能で構成される。問題を検証してPRにコメントを投稿する「Code Review」、CIの失敗・マージコンフリクト・レビューコメントに対応してPRをマージ可能な状態に保つ(承認・マージ自体は行わない)「PR Steward」、リポジトリ内のポリシーファイルに基づいて承認するかを判断する「Claude Approvals」の3つで、全体はβ版。Claudeの「Team」「Enterprise」プランのユーザーがGitHubリポジトリで利用できる。エージェントの稼働場所や人間の承認が必要な変更はチームが設定でき、Claude Approvalsはまず承認せずに判断結果だけを確認する「観察専用モード」での試用が推奨されている。Claude Codeには新コマンド「/ship」が追加され、プッシュからPR作成・レビュー・指摘への対応までを一通り進められる(マージの可否は開発者の権限とブランチルールで決まる)。料金はトークン使用量に応じた従量課金で、Anthropicは、AIがバグやセキュリティ上の脆弱性を見逃す可能性があると注意を促している。

## 今日のTips: TypeScriptの`satisfies`演算子、型注釈と違い値の推論型を保ったまま適合チェックできる

TypeScript 4.9で導入された`satisfies`演算子は、値がある型に適合しているかを検証しつつ、変数自体の型は式から推論された最も具体的な型のまま保つための構文だ。通常の型注釈`: T`で同じことをすると適合チェックはできるものの、変数の型が`T`に置き換わってしまい、プロパティ固有の型情報が失われる。

```ts
type Colors = "red" | "green" | "blue";
type RGB = [number, number, number];

const palette = {
  red: [255, 0, 0],
  green: "#00ff00",
  blue: [0, 0, 255],
} satisfies Record<Colors, string | RGB>;

palette.green.toUpperCase(); // green は string と推論されるのでOK
```

<Tip>`satisfies`はキーの不足・過剰も検出できる(例: `Record<Colors, unknown>`に`platypus`という余分なキーを持つオブジェクトを当てはめるとエラーになる)。型注釈と違い「適合チェックだけ行い、型は推論に任せる」ため、オブジェクトリテラルの検証に向いている。</Tip>

参考: [Announcing TypeScript 4.9 | TypeScript Blog](https://www.typescriptlang.org/docs/handbook/release-notes/typescript-4-9.html)
