## 今日のTips: PostgreSQL 12以降、CTEは既定で「最適化フェンス」にならずインライン展開される

PostgreSQL 11以前は`WITH`句(CTE)を使うと必ず先にその部分だけが評価され、外側のクエリとは独立した「最適化フェンス」として扱われていた。PostgreSQL 12からはこの挙動が変わり、副作用がなく非再帰的でクエリ内で1回だけ参照されるCTEは既定で外側のクエリにインライン展開されるようになった。

```sql
-- 既定(PG12+)ではインライン展開され、述語がCTE内部まで押し込まれる
WITH t AS (SELECT * FROM big_table)
SELECT * FROM t WHERE id = 1;

-- 従来どおりフェンスとして先に評価させたい場合は MATERIALIZED を明示
WITH t AS MATERIALIZED (SELECT * FROM big_table)
SELECT * FROM t WHERE id = 1;
```

<Tip>複数回参照されるCTEは既定ではインライン展開されないが、`NOT MATERIALIZED`を指定すれば強制的に展開できる。「CTEは最適化フェンスになる」という11以前の知識のまま`WITH`を副作用のない一時的な名前付けに使っていると、PG12以降では意図せず実行計画が変わることがあるため、フェンスとして固定したい処理には明示的に`MATERIALIZED`を付けるとよい。</Tip>

参考: [PostgreSQL 12 Release Notes](https://www.postgresql.org/docs/12/release-12.html)
