## 今日のTips: `node --run`、`npm run`と違い`pre`/`post`スクリプトを実行しない

Node.js v22で追加された`node --run`は、`package.json`の`scripts`を`npm run`より軽量に実行するためのフラグ。ただし公式ドキュメントは「意図的な制限(Intentional limitations)」として、`pre`/`post`スクリプトの実行とパッケージマネージャ固有の環境変数の定義をあえて対象外にしていると明記している。

```json
{
  "scripts": {
    "pretest": "echo setup",
    "test": "vitest run"
  }
}
```

`npm run test`なら`pretest`も実行されるが、`node --run test`は指定した`test`スクリプトのみを実行し、`pretest`は走らない。`--env-file`で読み込んだ環境変数も`--run`実行対象のコマンドには適用されない点も併記されている。

<Tip>`--run`実行時には、実行中のスクリプト名を示す`NODE_RUN_SCRIPT_NAME`と、処理対象の`package.json`のパスを示す`NODE_RUN_PACKAGE_JSON_PATH`が環境変数として自動的にセットされる。</Tip>

参考: [Node.js — Command-line API: --run](https://nodejs.org/api/cli.html#--run)
