## Anthropic、「Claude」にチーム共同編集の「Sheets」「Whiteboards」追加 外部アプリも全画面編集可能に

## 今日のTips: Node.jsの`unhandledRejection`、v15以降はデフォルトでプロセスがクラッシュする

Node.jsのPromiseが`reject`されてもハンドラが付いていない場合、`--unhandled-rejections`フラグの既定モード`throw`により、未処理のrejectionはuncaught exceptionとして扱われる。v15.0.0より前は既定が`warn`で警告を出すだけだったが、v15.0.0で既定が`throw`に変わったため、`unhandledRejection`を拾わないコードはNode.jsのバージョンを上げただけでプロセスが落ちるようになる。

```js
// unhandledRejectionハンドラが無いと、このrejectは
// uncaught exceptionとしてプロセスをクラッシュさせる(v15+の既定)
Promise.reject(new Error("oops"));

process.on("unhandledRejection", (reason) => {
  console.error("Unhandled Rejection:", reason); // ここで拾えばクラッシュを防げる
});
```

<Tip>`strict`モードにすると、ハンドラの有無に関わらず常にuncaught exceptionとして扱われ、ハンドラ側で処理された場合のみ`unhandledRejection`イベントが発行される(挙動が`throw`と逆)。</Tip>

参考: [`--unhandled-rejections=mode` – Node.js](https://nodejs.org/api/cli.html#--unhandled-rejectionsmode)
