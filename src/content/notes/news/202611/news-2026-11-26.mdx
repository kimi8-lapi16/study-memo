## パスワード管理「1Password」開発元に不正アクセス、従業員のGitHubアカウント侵害が発端

パスワード管理サービス「1Password」を手掛けるAgileBits(カナダ)は11月25日(現地時間)、従業員の業務用GitHubアカウントが侵害されたことを発端とする不正アクセスがあったと発表した。

セキュリティインシデント・脆弱性案件(本日1件目、最大3件枠)。11月19日に不審なアクセスの兆候を検知して調査したところ、攻撃者は侵害したGitHubアカウントでソースコードにアクセスし、バックエンドサービスに悪意のあるコードを送り込んで顧客のアカウント管理情報を取得、非公開リポジトリのコピーやCI/CD環境へのアクセスも確認された。侵入経路と攻撃者の身元は未公表。流出した可能性があるのは氏名・メールアドレス・アカウントID、招待や復旧用メールのトークン、公開鍵、SRPパラメータなどで、影響を受けた顧客数は非公表。一方、保管庫(Vault)内のデータや暗号化鍵、アプリ・ブラウザ拡張機能への影響はないとしている。GitHubアカウントの無効化や盗まれたトークンの失効、認証コードの桁数強化(6桁数字→10文字英数字)などの対応を実施済みで、パスワードやSecret Keyの変更は不要としつつ、招待・復旧を装ったフィッシングへの注意を呼びかけている。

## MCPに新機能「Skills over MCP」、ツールの使い方をサーバから配信可能に

AnthropicはMCP(Model Context Protocol)の新機能「Skills over MCP」をベータ版として追加した。

新技術紹介案件。従来、ツールの使い方を示すスキル(`SKILL.md`などのファイル)はエージェントの実行環境ごとに個別配置する必要があり、ツール更新後もスキルが古いまま残ったり、多数のスキルを最初から読み込むことでコンテキストを無駄に消費したりする課題があった。Skills over MCPでは、MCPサーバからツールの操作手順に加えてスキルそのものも取得できるようになり、エージェントは外部ツールの最新スキルを常に得つつ必要なときだけ読み込めるため、コンテキストを効率的に使える。ClaudeおよびClaude CodeのPro/Max/Ultraプランではデフォルトで有効になるという。

## 今日のTips: NestJSのリクエストスコープなprovider、依存関係を遡って広がりコントローラーごと再生成される

NestJSのproviderは既定ではシングルトン(`DEFAULT`スコープ)だが、`@Injectable({ scope: Scope.REQUEST })`のようにリクエストスコープを指定すると、そのproviderに依存する側も自動的にリクエストスコープへ"伝播"する。

```ts
// CatsController <- CatsService <- CatsRepository という依存関係で
// CatsService だけをリクエストスコープにすると…
@Injectable({ scope: Scope.REQUEST })
export class CatsService {}

// CatsController もリクエストスコープになる(CatsRepositoryは無関係のまま伝播しない)
```

<Tip>DB接続やロガーのような多くのprovidersが依存する共通providerをリクエストスコープにすると、それに依存する全providerが連動してリクエストスコープ化してしまう。NestJS公式は、同時に3万件のリクエストが来れば3万個の一時的なコントローラーインスタンスが生まれる例を挙げて警告しており、レスポンスタイムの悪化(目安5%程度)にもつながるため、本当に必要な場合を除きシングルトンのままにし、リクエスト固有の値だけが要るなら`AsyncLocalStorage`ベースのリクエストストアを検討するとよい。</Tip>

参考: [NestJS Docs - Injection Scopes](https://docs.nestjs.com/fundamentals/injection-scopes)
