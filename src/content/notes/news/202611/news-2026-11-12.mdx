## Google DeepMind、「AlphaGenome 2」発表 細胞の種類ごとにDNA変異の影響を予測するAI

Google DeepMindは11月11日(現地時間)、DNA配列やその変異がヒトの特定の細胞の種類にどう影響するかを予測するAIモデル「AlphaGenome 2」を発表した。

AI・LLM動向案件。2025年6月発表の初代AlphaGenomeは組織単位で遺伝子の働きを予測していたが、AlphaGenome 2は予測対象の組織・細胞の種類・細胞の状態を条件として指定できるようにした。ヒトとマウスの68組織、1億を超える細胞のデータで学習し、遺伝子のオン/オフに関わる「DNAメチル化」も予測対象に加えた。研究者が自分の実験で得た数十個程度の細胞データを入力すれば、再学習なしでその状態に合わせた予測ができる点が特徴で、遺伝子の働きを変える変異の検出力は従来最高水準のモデルの約2倍としている。炎症性腸疾患(IBD)に関する既存研究の再現にも成功したという。研究目的は「AlphaGenome API」経由で利用でき、商用の研究向けは限定プレビューで提供される。臨床・診断用途の検証は受けていない。

## 今日のTips: TypeScriptの`using`宣言、スコープを抜けるとき`Symbol.dispose`を自動で呼んでくれる

TypeScript 5.2で導入された`using`宣言は`const`に似た構文だが、スコープを抜けるとき(正常終了・早期`return`・例外のいずれでも)に値の`[Symbol.dispose]()`を自動で呼び出す。`try`/`finally`を書かずに、DB接続やファイルハンドルなどの後始末を保証できる。

```ts
class Conn implements Disposable {
  [Symbol.dispose]() {
    console.log("close connection");
  }
}

function run() {
  using conn = new Conn();
  if (Math.random() > 0.5) return; // ここでも dispose が呼ばれる
  // conn を使う...
} // スコープ終了時にも dispose が呼ばれる
```

非同期の後始末には`Symbol.asyncDispose`を実装し`await using`で宣言する。複数の`using`はLIFO順(後入れ先出し)で破棄され、本体と`dispose`の両方で例外が起きた場合は`SuppressedError`にまとめられる。ネイティブ対応ランタイムは無いため、`tsconfig.json`の`lib`に`esnext.disposable`を加え、`Symbol.dispose`のポリフィルが必要。

<Tip>NestJSなどでDB接続やトランザクションのリソース解放に使うには、別途`Symbol.dispose`/`Symbol.asyncDispose`のランタイムポリフィルが必要(TypeScript側のシンボル型定義だけでは実行時に存在しない)。</Tip>

参考: [TypeScript 5.2 Release Notes — Using Declarations and Explicit Resource Management](https://www.typescriptlang.org/docs/handbook/release-notes/typescript-5-2.html)
