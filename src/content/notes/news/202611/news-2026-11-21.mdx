## Claude Codeに実験機能「Code Mode」 複数ツールをまとめて動かすJavaScriptを生成

Anthropicは、CLIツール「Claude Code」に、複数のツール呼び出しをつなぐJavaScriptを生成して実行する実験機能「Code Mode」を追加した。

開発ツール・言語・OSS動向案件。通常のツール呼び出しでは、Claudeは1回ごとに出力を読んで次の行動を判断するが、Code Modeでは一連の手順をスクリプトとしてまとめて実行し、途中結果を都度Claudeに返す必要がなくなる。大量の検索結果をスクリプト側で絞り込んで必要な部分だけを返したり、多数のファイルへの同じ変更や複数コマンドの並列実行をまとめて行うのに向くという。待機完了の場合はスクリプトの実行時間上限が10分、バックグラウンド実行では最長2時間まで動かせる。利用にはネイティブ版Claude Code v2.1.323以降かつターミナルの対話型セッションが必要で、VS Code拡張パネルやデスクトップアプリ、ゲートウェイ経由の接続(Amazon Bedrock等)、HIPAA対応設定やゼロデータ保持を有効にした組織では使えない。既定では無効で、環境変数`CLAUDE_CODE_EXPERIMENTAL_CODE_MODE`を`1`に設定して有効化する。

## 今日のTips: Prismaの対話型トランザクション、既定では5秒で自動タイムアウトする

Prismaの`$transaction`にコールバックを渡す「インタラクティブトランザクション」には、トランザクションを確保するまでの最大待ち時間`maxWait`(既定2000ms)と、トランザクション自体の最大実行時間`timeout`(既定5000ms)が設定されている。ネットワークリクエストや遅いクエリをトランザクション内で実行すると、既定の5秒をすぐに超えてしまう。

```ts
await prisma.$transaction(
  async (tx) => {
    await tx.order.create({ data: orderData });
    await tx.inventory.update({
      where: { id },
      data: { stock: { decrement: 1 } },
    });
  },
  { timeout: 10000 }, // 既定は5000ms
);
```

<Tip>Prisma公式も「トランザクションはできるだけ短く保ち、ネットワークリクエストや遅いクエリの実行は避けるべき」と注意している。長時間トランザクションを開いたままにするとデータベース性能を損ない、デッドロックの原因にもなる。</Tip>
