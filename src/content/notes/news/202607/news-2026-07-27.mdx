## 今日のTips: TypeScriptのcatch節の変数は、strictモードでは既定でunknown型になる

TypeScript 4.4で追加された`useUnknownInCatchVariables`は`strict`ファミリーに含まれており、`strict: true`にしていれば自動的に有効になる。これにより`catch`節の変数は`any`ではなく`unknown`型として扱われる。

```ts
try {
  JSON.parse(input);
} catch (err) {
  // err の型は unknown。プロパティに直接アクセスするとコンパイルエラーになる
  console.error(err.message); // Error: Property 'message' does not exist on type 'unknown'
}
```

`unknown`はどんな型でも代入できる一方、使う前に型を絞り込む（narrowing）ことを強制する型なので、`instanceof`などで安全に絞り込んでからアクセスする必要がある。

```ts
try {
  JSON.parse(input);
} catch (err) {
  if (err instanceof Error) {
    console.error(err.message); // OK
  }
}
```

<Tip label="▶ 補足">
TypeScript 4.3以前の挙動に戻したい（＝チェックを緩めたい）場合は、`catch (err: any)`のように明示的に型注釈を付ければオプトアウトできる。
</Tip>
