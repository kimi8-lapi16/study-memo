## 中国Z.ai、オープンモデル「GLM-5.3」を無償公開 Claude Opus 4.8上回る性能を主張

中国のAI企業Z.aiは8月29日0時（日本時間）、大規模言語モデル「GLM-5.3」をオープンモデルとして無償公開した。

AI・LLM動向案件。総パラメーター数7440億で、評価機関Artificial Analysisのベンチマークでは「Claude Opus 4.8を上回るインテリジェンス性能」を獲得したとされ、Claude Fable 5やGPT-5.6 Solに匹敵する性能とうたう。HuggingFaceとModelScopeからダウンロード可能で、軽量な量子化版も提供されており、高性能なPC環境があれば実行できる。ライセンスは無償利用が基本だが、年間収益が100億ドルを超える企業はZ.aiのセキュリティ審査に合格する必要があると定められている。

## Anthropic、AIにロボットアームや顕微鏡を操作させる共通規格「Model Hardware Standard」を発表

Anthropicは8月27日、AIエージェントが実験機器や製造装置などの物理機器を共通の方法で操作できるようにする規格「Model Hardware Standard（MHS）」のリサーチプレビューを開始したと発表した。

新技術紹介案件。従来はメーカーごとに操作方法やプログラミング要件が異なり、複数装置を組み合わせた自動化には数週間から数カ月かかることもあったが、MHSは機器の特徴や安全上の制限に関する情報を標準化されたドライバーとして扱うことで、統合作業を数時間から数分に短縮できるとしている。研究用顕微鏡の調整やレーザーの復旧作業にClaudeを使った実証例も紹介された。特定のAIモデルに依存しない設計で、Doosan RoboticsやUniversal Robots、Hugging Face、Raspberry Piなどが統合に取り組んでいるという。現時点では一部組織向けのリサーチプレビューだが、将来的にオープンソース化する方針。

## 英マンチェスター空港運営会社に不正アクセス、旅客870万人分のデータ流出

英国の空港運営会社Manchester Airports Group（MAG）は8月27日、傘下のマンチェスター・ロンドンスタンステッド・イーストミッドランズの3空港の顧客データが不正アクセスにより流出したと公表した。

セキュリティインシデント・脆弱性案件（最大3件枠）。流出したのは主に空港Wi-Fi登録時のメールアドレスで、一部利用者については駐車場・ラウンジ・優先セキュリティ通過の予約に紐づく氏名・住所・電話番号・郵便番号・車両登録番号も含まれるという。地元報道では最大870万人分の旅客情報が対象とされる。攻撃者はデータと引き換えに身代金を要求したが、MAGは支払いを拒否した。決済情報の流出はなく、空港運用への影響も無いとしている。

## 米ATF（アルコール・タバコ・火器局）にランサムウェア攻撃、Qilinが関与主張

米ATF（Bureau of Alcohol, Tobacco, Firearms and Explosives）は8月27日、システムの一部が侵害された「重大インシデント」を確認したと発表した。同日、ランサムウェア集団QilinがダークウェブのリークサイトにATFを標的として掲載していた。

## 今日のTips: Prismaの`omit`で、パスワードなど機密フィールドをレスポンスから常時除外する

Prisma ORM 6.2.0（2025年1月9日リリース）で、クエリ結果から特定フィールドを除外する`omit`APIがプレビューを卒業しGA（安定版）になった。

```ts
const prisma = new PrismaClient({
  omit: {
    user: { password: true },
  },
});
```

クライアント初期化時にこう書けば、以降`prisma.user.findMany()`などの結果から`password`フィールドが自動的に除かれる。`select`で必要なフィールドだけを毎回列挙する代わりに、「常に隠したい機密フィールド」をグローバルに一箇所で管理できるのが利点。個別クエリだけ除外したい場合はクエリオプションに`omit: { password: true }`を渡せばよい。

<Tip label="▶ 補足">
`select`と`omit`は同じクエリ内で併用できない（同じフィールドの扱いが競合するため）。両方の設計思想が要る場合は、グローバル`omit`で機密フィールドを隠しつつ、個別クエリでは`select`ではなく`include`で関連データを絞り込む使い分けが基本になる。
</Tip>
