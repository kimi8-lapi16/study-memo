## 今日のTips: React 19、refをforwardRefなしで通常のpropとして受け取れるようになった

関数コンポーネントは、React 19からrefを通常のpropとして直接受け取れるようになった。従来はrefを子コンポーネントへ渡すために`forwardRef`でラップする必要があったが、この変更で不要になる。

```jsx
function MyInput({ placeholder, ref }) {
  return <input placeholder={placeholder} ref={ref} />;
}

// forwardRefなしでrefを渡せる
<MyInput ref={inputRef} placeholder="name" />;
```

<Tip label="▶ 補足">
新規の関数コンポーネントは`forwardRef`が不要になり、既存コードを自動変換するcodemodも公式から提供されている。将来のバージョンで`forwardRef`自体が非推奨・削除される予定。ただしクラスコンポーネントに渡す`ref`はインスタンス参照のため、引き続きpropsとしては渡されない。
</Tip>
