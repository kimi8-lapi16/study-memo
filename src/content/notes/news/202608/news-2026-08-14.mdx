</Note>

## トランプ大統領、民間企業によるサイバー攻撃作戦を容認する覚書に署名

トランプ米大統領は8月12日、国境を越えたサイバー犯罪への対処能力を拡大するとする大統領覚書に署名した。審査を通過した民間企業が連邦政府の監督下でサイバー作戦を実施できるプログラムの創設を指示する内容。

## 今日のTips: TypeScript 5.4の`NoInfer`、ジェネリック関数の型パラメータを特定引数の推論から除外する

TypeScriptのジェネリック関数は、デフォルト値を渡す引数からも型パラメータを推論してしまうため、意図しない値を通してしまうことがある。

```ts
function createStreetLight<C extends string>(
  colors: C[],
  defaultColor?: C
) {}

createStreetLight(["red", "yellow", "green"], "blue");
// "blue" は colors に無いのに C が "red"|"yellow"|"green"|"blue" と推論され、エラーにならない
```

TypeScript 5.4で追加された`NoInfer<T>`で`defaultColor`の型を包むと、その引数を型推論のソースから除外できる。

```ts
function createStreetLight<C extends string>(
  colors: C[],
  defaultColor?: NoInfer<C>
) {}

createStreetLight(["red", "yellow", "green"], "blue");
// Error: Argument of type '"blue"' is not assignable to parameter of type '"red" | "yellow" | "green"'.
```

<Tip label="▶ 補足">
`NoInfer`は「この位置の値を型推論に使わない」という意思表示。デフォルト値やコールバックの戻り値など、他の引数で確定した型パラメータを"受け取る側"にのみ使い、"決める側"の引数には使わないのが基本。
</Tip>
