## 今日のTips: structuredCloneはJSON.stringify/parseと違い循環参照を扱えるが、関数は渡すとエラーになる

JavaScript/Node.jsの組み込み関数`structuredClone()`（Node.js v17以降でグローバル利用可）は、オブジェクトのディープコピーによく使われる`JSON.parse(JSON.stringify(obj))`と異なり、循環参照を保持したままクローンできる。Date・Map・Set・RegExpなども文字列化されずそのままの型で複製される。

```js
const original = { name: "MDN" };
original.itself = original; // 循環参照

const clone = structuredClone(original);
clone.itself === clone; // true（循環参照も保持）

structuredClone({ fn: () => {} });
// DataCloneError (DOMException) が throw される
```

<Tip label="▶ 補足">
関数・シンボル・DOM要素など「シリアライズ不可能な値」を含めると`DataCloneError`が投げられる点はJSON方式にはない挙動。JSON.stringify/parseは関数を黙って無視するため、うっかり値が消えていることに気づきにくいが、structuredCloneは失敗が明示的に分かる。
</Tip>

参考: [MDN: structuredClone()](https://developer.mozilla.org/en-US/docs/Web/API/Window/structuredClone)
