## 今日のTips: TypeScriptの`const`型パラメータで、`as const`なしにリテラル型を推論させる

ジェネリック関数は通常、呼び出し時に渡した配列リテラルを`string[]`のような広い型に推論するため、要素のリテラル型や`readonly`タプルとして扱いたい場合は呼び出し側で毎回`as const`を書く必要があった。

```typescript
type HasNames = { names: readonly string[] };

function getNames<T extends HasNames>(arg: T): T["names"] {
  return arg.names;
}
function getNamesConst<const T extends HasNames>(arg: T): T["names"] {
  return arg.names;
}

// 推論型: string[]
const loose = getNames({ names: ["Alice", "Bob"] });
// 推論型: readonly ["Alice", "Bob"]（as const不要）
const strict = getNamesConst({ names: ["Alice", "Bob"] });
```

TypeScript 5.0で追加された`const`型パラメータは、型パラメータに`const`修飾子を付けるだけで呼び出し側の`as const`を省略でき、既定の推論を「できるだけ具体的な型」に切り替えられる。

<Tip label="▶ 補足">
制約に`string[]`のような可変型を使うと`readonly`配列が代入できず期待通りに推論されないため、`<const T extends readonly string[]>`のように制約自体も`readonly`にする必要がある。また`const`修飾子が効くのは呼び出し時に書かれたリテラルのみで、既存の変数を渡した場合は通常通り広い型に推論される。
</Tip>

参考: [TypeScript 5.0 Release Notes - const Type Parameters](https://www.typescriptlang.org/docs/handbook/release-notes/typescript-5-0.html)
