## 今日のTips: `Object.groupBy()`の戻り値はnullプロトタイプオブジェクト、`hasOwnProperty`が呼べない

ES2024で追加された`Object.groupBy()`は、配列などのイテラブルをコールバックが返す文字列キーでグループ化できる静的メソッド。Node.jsは21以降で標準搭載している。

```js
const items = [
  { name: "a", type: "fruit" },
  { name: "b", type: "veg" },
];
const grouped = Object.groupBy(items, ({ type }) => type);
grouped.hasOwnProperty("fruit"); // TypeError: grouped.hasOwnProperty is not a function
```

<Tip label="▶ 補足">
戻り値は`Object.prototype`を継承しないnullプロトタイプオブジェクトのため、`hasOwnProperty`や`toString`などのメソッドは呼び出せない。存在確認には`"fruit" in grouped`や`Object.hasOwn(grouped, "fruit")`を使う。プロトタイプ由来のプロパティと衝突しない、意図された設計。
</Tip>
