## 今日のTips: PostgreSQLのCTE（WITH句）、単一参照なら自動でインライン化される

PostgreSQL 11以前ではWITH句は常に「最適化の壁」として扱われ、CTEの中身は必ず一旦マテリアライズ（実体化）されてからしか外側のクエリと結合できなかった。

```sql
-- 非再帰的・副作用なし・親クエリから1回だけ参照 → 自動でインライン化
WITH w AS (
  SELECT * FROM big_table
)
SELECT * FROM w WHERE key = 123;
-- big_table に対する WHERE 句のプッシュダウンやインデックス利用が効く

-- 複数回参照する場合は今まで通りマテリアライズされる
WITH w AS (
  SELECT * FROM big_table
)
SELECT * FROM w w1 JOIN w w2 ON w1.key = w2.ref;
```

PostgreSQL 12以降は、非再帰的かつ副作用のない（volatile関数を含まない）CTEが親クエリから1回しか参照されない場合、デフォルトでインライン化されるようになった。これにより述語のプッシュダウンやインデックス利用など通常のクエリと同等の最適化が効くようになり、旧来「WITH句に入れると遅くなる」という定石が一部当てはまらなくなっている。

<Tip label="▶ 補足">
挙動はキーワードで明示的に上書きできる。関数の重複評価を避けたい場合は`WITH w AS MATERIALIZED (...)`で強制的に実体化し、複数回参照するCTEでもプッシュダウンを効かせたい場合は`WITH w AS NOT MATERIALIZED (...)`で強制的にインライン化できる（後者は重複計算のリスクとのトレードオフ）。
</Tip>
