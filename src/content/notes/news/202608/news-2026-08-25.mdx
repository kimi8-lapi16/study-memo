## 今日のTips: `Promise.withResolvers()`で、resolve/rejectを外側のスコープに取り出せる

これまで、Promiseのexecutor関数の外でresolve/rejectを使いたい場合、一度`let`で変数を宣言してからexecutor内で代入するという回りくどい書き方が必要だった。

```js
// 従来の書き方
let resolve, reject;
const promise = new Promise((res, rej) => {
  resolve = res;
  reject = rej;
});

// Promise.withResolvers()を使った書き方
const { promise, resolve, reject } = Promise.withResolvers();
```

ES2024で追加された`Promise.withResolvers()`は、`promise`・`resolve`・`reject`の3つを持つオブジェクトを直接返すため、このラップが不要になる。ストリームのイベントハンドラのように「外部のコールバックからPromiseを解決したい」場面で特に有効で、ループのたびに新しいPromiseを作り直すようなパターンとも相性がいい。

<Tip label="▶ 補足">
Node.jsではv22.9以降で利用可能。それ以前のバージョンをサポートする必要がある場合は、従来通り`new Promise()`にexecutorを渡す書き方を使う。
</Tip>
