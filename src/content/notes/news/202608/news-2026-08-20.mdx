## 今日のTips: `satisfies`演算子で、型チェックと具体的な型推論を両立させる

TypeScriptで値がある型に沿っているかをチェックしたいとき、変数に型注釈を付けると型チェックはできるが、各プロパティの具体的な型情報が失われてしまう。TypeScript 4.9で導入された`satisfies`演算子は、型チェックをしつつ元の式が持つ最も具体的な型を保持できる。

```ts
type Colors = "red" | "green" | "blue";

const palette = {
  red: [255, 0, 0],
  green: "#00ff00",
  bleu: [0, 0, 255], // ← "bleu" のタイプミスをここで検出できる
} satisfies Record<Colors, string | number[]>;

palette.green.toUpperCase(); // green は string と推論されるのでOK
```

<Tip label="▶ 補足">
`const palette: Record<Colors, string | number[]> = {...}`のように型注釈を付けると、この検出とプロパティごとの型推論はどちらも失われる（`palette.green`は`string | number[]`型になり`toUpperCase()`が呼べない）。「型に合っているかの検証」と「値そのものの型を保ちたい」を両立したい場面が`satisfies`の使いどころ。
</Tip>

参考: [TypeScript 4.9 Release Notes - satisfies Operator](https://www.typescriptlang.org/docs/handbook/release-notes/typescript-4-9.html)
