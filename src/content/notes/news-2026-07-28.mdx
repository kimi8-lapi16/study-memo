## Vercel、TypeScriptをC言語経由でネイティブバイナリにコンパイルする「scriptc」をOSS公開

Vercelは、Node.jsで動くTypeScriptコードをコードの変更なしにネイティブな実行ファイルへコンパイルするツール「scriptc」をオープンソースで公開した。

開発ツール・言語・OSS動向案件。既存のNode.js/Deno/Bunがランタイムとコードをパッケージ化するだけなのに対し、scriptcはTypeScriptを型付き中間表現に変換したうえでC言語コードに落とし込み、Clangでコンパイルする。これによりJavaScriptランタイムに依存しないバイナリが生成され、Node.jsで60〜100MBあったアプリのサイズが170〜200KBまで縮小、Appleシリコン搭載Macでの起動時間も47ミリ秒から2.4ミリ秒以下に短縮されるという。

## 今日のTips: PostgreSQL 11以降、定数DEFAULT付きのカラム追加はテーブル書き換え不要になった

PostgreSQL 10以前は、既存テーブルに`NOT NULL DEFAULT`付きのカラムを追加すると、テーブル全体を書き換える処理が走り、大きなテーブルでは長時間のロックが発生していた。PostgreSQL 11ではこの挙動が改善され、デフォルト値が定数の場合はテーブル書き換えなしでカラムを追加できるようになった。

```sql
-- テーブル書き換えなしで一瞬で完了する（PostgreSQL 11以降）
ALTER TABLE users ADD COLUMN plan_type text DEFAULT 'free' NOT NULL;
```

この最適化はカタログにデフォルト値を保持し、変更時点で既存の行に対してはそれを参照する仕組みで実現されている。ただし`random()`や`now()`のようなvolatile（揮発性）な式をデフォルトに使う場合はこの最適化の対象外で、従来通りテーブル書き換えが発生する点には注意したい。

<Tip label="▶ 補足">
行ごとに異なる値が必要になるvolatileなデフォルト式では、カタログに単一の値を保持するだけでは済まないため、この最適化が使えない。
</Tip>

参考: [PostgreSQL 11.0 Release Notes](https://www.postgresql.org/docs/11/release-11.html)
