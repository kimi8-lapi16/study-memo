## AMD、AIモデルの「重み」を半導体に直接焼き込むTaalasを買収

AMDは8月6日、AIモデルの構造とパラメーター（重み）を半導体に直接組み込む技術を持つカナダのスタートアップTaalasを買収すると発表した。

業界動向案件。Taalasは完成した専用半導体を「Hardcore Models」と呼び、メモリから重みを大量に読み出す処理を減らすことでAI推論を高速化する。第1世代の試作機「HC1 Technology Demonstrator」ではMetaの「Llama 3.1 8B」を組み込み、ハードウェア構築コストを従来比20分の1、消費電力を10分の1に削減できたという。AMDはこの技術をInstinct GPUと組み合わせ、多様なAIワークロードに対応するフルスタックのAIプラットフォームを構築する計画。買収金額は非公表。

## Google、AIエージェントのスキル・MCPサーバーを持ち運べる「Agent Plugins」に参加

Googleは、AIエージェントのスキルとMCPサーバーをまとめて異なるクライアント間で持ち運べるオープン仕様「Agent Plugins」のコア保守者に加わった。

## Google DeepMind、台風進路予測モデル「WeatherNext Cyclones」を公開

Google DeepMindは、台風・ハリケーン・サイクロンの進路・強度・風構造を予測するモデル「WeatherNext Cyclones」を発表し、研究コミュニティ向けにGitHubでオープン化すると明らかにした。

新技術紹介案件。3日先の予報精度が従来モデルの2日先予報と同等になったとしており、気象学の進歩として10年分に相当する改善という。主要な気象予測モデルと比べて平均1日以上のリードタイム優位性を確保できるとし、2025年のハリケーン「メリッサ」の勢力増大とジャマイカ上陸を的中させた実績も紹介している。2026年シーズンでは1000通りの想定シナリオ予測を提供し、気象予報士の意思決定を支援する。

## Metabaseの重大SQLiがゼロデイ攻撃で悪用、Framework・Tallyなどが被害

BIツール「Metabase」に存在した未認証のSQLインジェクション脆弱性（CVSS 10.0）がゼロデイ攻撃で悪用され、ノートPCメーカーFrameworkとフォーム作成サービスTallyがデータ窃取被害を受けたことが分かった。

セキュリティインシデント・脆弱性案件。脆弱性はバージョン1.58以降のMetabaseに存在し、攻撃者は任意のSQLを注入して管理者権限を奪取できた。Frameworkでは氏名・メールアドレス・ログインIP・請求先/配送先住所・電話番号・会社名が、Tallyではメールアドレスとパスワードハッシュ（暗号化アルゴリズムは未確認）が流出。Metabaseを利用するLexisNexisも第三者経由で影響を受けた可能性があるが詳細は不明という。両社とも8月3日に侵害を受けたとしており、Metabaseは修正版（1.58.24・1.59.21・1.60.17・1.61.11・1.62.9・1.63.5）を公開済み。

<Note label="⚠ 注意">
自社ホストのMetabaseを使っている場合は、対象バージョンなら直ちにパッチ適用が必要。CVSS満点の未認証脆弱性であるため放置は危険。
</Note>

## 今日のTips: TypeScript 5.5の型述語推論、`filter`の後に`undefined`が消えるようになった

TypeScript 5.5から、`array.filter(x => x !== undefined)`のような単純な絞り込み関数は、明示的な型注釈なしでも戻り値の型が`x is T`という型述語として自動推論されるようになった。5.4以前は`filter`後も`(Bird | undefined)[]`のままだったが、5.5以降は`Bird[]`に絞り込まれる。

```typescript
const birds = countries
  .map(c => nationalBirds.get(c))
  .filter(b => b !== undefined); // 5.5+: Bird[]
```

<Tip label="▶ 補足">
この推論は「trueなら絞り込み対象、falseなら対象外」という双方向の意味を持つ型述語の性質上、`filter(score => !!score)`のような単なる真偽値チェック（truthinessチェック）には効かない。`0`のような falsy な有効値まで除外対象と誤認識されるため、`!== undefined`のように比較対象を明示する必要がある。
</Tip>

参考: [TypeScript 5.5 Release Notes: Inferred Type Predicates](https://www.typescriptlang.org/docs/handbook/release-notes/typescript-5-5.html)
