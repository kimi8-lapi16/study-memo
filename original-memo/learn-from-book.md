# タイトル
血肉となる読書

## はじめに
- 筆者は読書をする時に「自分に対する手紙」だと思って本を読むそう
  - そうすることによって、単純な文字の羅列ではなく、自分ごととして捉えることができ、考えを深めるきっかけに繋がると考えている

## 第一章 本はどう読むか
- 先行きが不透明な時代にあって、チープな知識で一過性のマニュアルでは太刀打ちできず、それこそAIに取って代わられる。その上での読書する意義とは以下のようなものがあるのではないだろうか
  - 未知の危機にも対応できる、時代を超えた心理を獲得すること
  - そのような解決策を見つけるために必要な考える力そのものを養うこと
- 1冊の本により、今までの価値観がひっくり返される「コペルニクス的転回」を得られることもある
- 現実の問題への関心や認識が先にあって、そこから問題を考えるために必要なテキストへ返っていく
- 本を読むことで養われる「考える力」が重要であるが、特に意識したい読み方として、同時代の流行り物ではなく、過去の名著を読むこと
- 社会状況が変わると、読み手の問題意識も変化し、わかったつもりになっていた本であっても、別の視点が浮かび上がってくる
- すべての本に同じように時間と熱量をかけるのは現実的ではないため、欲しい情報が載っていなかったり関連する情報が薄いと判断した場合は、ざっと内容を留める程度にしておく
- 逆に、重要だと感じられた本については何度も読み返す、全部ではなく本当に必要な一部だけを読み返す
- 本を読み進める際には、推論を立て、他の理論との違いを調べてみる、芋づる式な読み方も推奨されるが、単純に芋づる式(連想ゲーム)に読めば良いわけではない
- また、本を読んでいると違和感を覚える文に出会うこともあるが、その場合は一旦本に書かれていることを正しいものとして、理論を構築してみる。多くの場合では読み手の方が間違っている。しかし、その違和感のある一文のおかげで思考の差異を理解でき、ブレイクスルーを生むこともある
